# Agentic AI Music Listening Pattern Analyzer

A beginner-friendly Streamlit project that explores music listening patterns using a synthetic dataset and an optional LangGraph + OpenAI agent.

## Important data note
The first dataset is synthetic sample data generated by `data_utils.py`. It is not real Spotify listening history. Replace it later with your own permitted listening-history export.

## Run on Replit (mobile-friendly)
1. Create a Python Repl at https://replit.com/ using the mobile browser.
2. Upload the contents of this project, or import the ZIP.
3. Replit should detect `requirements.txt`; install the listed packages if prompted.
4. Run `streamlit run app.py`.
5. If the workspace asks for a run command, use exactly `streamlit run app.py`.

## Enable the AI agent
Add an environment secret named `OPENAI_API_KEY` in Replit's Secrets tool. Use your own API key from the provider. Do not put the key in source code or share it. API usage may incur charges.

Without the key, the dashboard and local demo question-answering still work. With the key, LangGraph can decide which read-only analytics tools to call to answer a question.

## Files
- `app.py`: Streamlit dashboard and question box.
- `data_utils.py`: creates and loads synthetic sample data.
- `music_agent.py`: local fallback and LangGraph agent tools.
- `requirements.txt`: Python package list.
- `data/`: generated CSV data is stored here.

## First test questions
- Which genre do I listen to most?
- Which artists are most popular?
- When do I listen to music most?
- How many minutes of music are in the dataset?

## Safety
The agent only receives read-only analytics tools. Do not add arbitrary SQL execution or unrestricted code execution.
